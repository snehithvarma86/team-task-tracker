# Team Task Tracker API

A production-ready REST API for a team-based task management system, built with Node.js, Express, TypeScript, and PostgreSQL.

## Quick Start (Zero-Config Setup)

This application is fully containerized. You do not need Node, Postgres, or Redis installed on your local machine to run it.

1. Ensure Docker Desktop is running.
2. Clone the repository and navigate into the directory.
3. Run the following command:

```bash
docker compose up --build
